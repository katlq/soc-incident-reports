# SOC Incident Reports

Репозиторий с отчётами по разбору инцидентов информационной безопасности.

Каждый отчёт структурирован с использованием двух моделей:
- **MITRE ATT&CK** — маппинг тактик и техник атакующего (таблица Tactic/Technique)
- **Cyber Kill Chain** — текстовое описание хронологии атаки по фазам (Reconnaissance → Actions on Objectives)

## О репозитории

Все инциденты разбираются самостоятельно, в учебных целях.

**Источники материалов:**
- [LetsDefend](https://letsdefend.io)
- Домашние SOC-лаборатории
